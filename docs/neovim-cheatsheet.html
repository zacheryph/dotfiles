Code & review

Act on code, triage problems, and keep editing flow. Context matters: completion mappings apply only while the popup menu is active.

modes: N normal   V visual   I insert

Language actions N · LSP

Space→c a
Code actionfix, import, refactor when offered
Space→r n
Rename symbolproject-aware rename
K
Hover docs / type info
Formatting is automatic on save. Lua uses Stylua; Nix uses nixfmt; JS/TS/JSON/YAML/Markdown use Prettier. LSP formatting is the fallback.

Gitsigns is always on: changed lines appear in the sign column, and current-line blame is shown automatically. No custom hunk keys are defined.
